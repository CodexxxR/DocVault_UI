To Run this project you would need docker in your machine as I am using Keycloak for authorization
Please follow the steps to run the DocVault locally:

---> cd to docvault_ui
---> in your terminal run docker compose up
---> one keycloak is successfully run, Open a new terminal
---> run npm run vite
---> open the loacalhost and sign in with sso it should open the keycloak ui please register yourself there.
